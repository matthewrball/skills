# Better UI

Small details compound. Concentric border radius. Optical over geometric alignment. Shadows for elevation, borders for structure. Interruptible animations (CSS transitions). Split and stagger infrequent entrances only. Subtle exits. Never `transition: all`. Scale on press at 0.96. Match icon stroke to text weight. Skip enter animation on page load.

Typography → better-typography. A11y → better-accessibility. Layout → better-layout.
