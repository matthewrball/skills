# Better Writing

Clear and brief beats clever. Recon the existing voice first. One voice, flexible tone. Address the reader as you. Plain words. Verb-first buttons. Consistent flow vocabulary. Links describe their destination. One capitalization policy. Settings describe the ON state. Errors say how to fix, next to where it broke. Empty states point forward.

How copy renders → better-typography. Error markup → better-accessibility.
