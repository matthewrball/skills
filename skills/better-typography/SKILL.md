# Better Typography

Good typography is restraint. Match the project's styling system. Serve woff2. Properties over raw font-variation-settings. Fewer fonts, sizes, and weights. Semantic type scale. Heading sizes descend with level. Line-height by role. Cap measure at 60–75ch. Wrap deliberately (balance on headings, pretty on descriptions). Tabular numbers on changing values. Truncate without losing content.

Copy itself → better-writing. Heading semantics → better-accessibility. Contrast → better-colors.
