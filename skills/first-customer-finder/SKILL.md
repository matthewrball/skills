# First Customer Finder

Turn a product URL or description into a short evidence-backed prospect list. Public signals only. Never claim someone will buy. Never send messages unless separately authorized.

Workflow: understand product → public-signal search plan → research safely → qualify/dedupe → draft outreach → produce the report (verdict, ICP, top prospect, shortlist, patterns, seven-day plan, limits).

Read `/workspace/user-skills/first-customer-finder/references/research-framework.md` and `report-artifact.md`. Report script: `scripts/generate_report.py`.
