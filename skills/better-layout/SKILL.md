# Better Layout

Layout communicates before a word is read. Group with space not lines. Keep controls distinct from content. Align to shared edges. Use logical properties. Order by importance. Hint at hidden content. Breathing room between targets. Content bleeds, controls float. Breakpoints from content, not device presets. Plan for i18n growth.

Hit areas → better-accessibility. Visual polish → better-ui. Line length → better-typography.
